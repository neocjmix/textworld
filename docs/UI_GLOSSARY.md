# Textworld UI 명칭 사전

현재 UI를 수정할 때 사용하는 공통 이름과 번호다. “C-4 중심 커서”, “D-6 GPS 이동 버튼”처럼 지칭할 수 있다. **C 월드 화면이 전체 화면이며, 내 커서는 이동이 끝나면 화면 중심보다 조금 위(높이의 43%)에 놓인다. 부드러운 이동 중에는 잠깐 중심을 벗어날 수 있다. 지도 이동 자체가 커서 이동이고, 지도 위에서 네이티브 키보드로 바로 입력한다.**

기존 번호를 다른 요소에 재사용하지 않는다. 제거된 요소도 번호와 이름을 남긴다. 이 문서는 현재 UI를 설명하며 `PRODUCT_CONSTITUTION.md`는 변경하지 않는다.

## 전체 구조

지도가 브라우저의 보이는 콘텐츠 영역 전체를 채운다. 예전처럼 A~F가 세로로 쌓여 지도 영역을 줄이지 않는다. 필요한 조작만 지도 위에 떠 있다.

```text
┌──────────────────────────────────────────┐
│ [연결·접속자]                      [공유] │
│                                          │
│                [내 커서]                 │
│             중심보다 조금 위              │
│                                          │
│          C. 전체 화면 월드맵              │
│                                          │
│                                    [GPS] │
└──────────────────────────────────────────┘
```

최초 접속 시 중앙에 로고가 3초간 나타난 뒤 사라진다. 상태 알림은 화면 아래쪽에 잠깐 표시한다.

모바일 키보드가 열리면 키보드를 제외한 **보이는 지도 영역의 중심보다 조금 위**으로 입력 셀이 부드럽게 이동한다. 전환 중에도 커서는 실제 입력 셀에 붙어 있다. 브라우저의 주소창이나 OS 화면까지 숨기는 Fullscreen API 모드를 뜻하지 않는다.

| A-2 | 로고 글자 | 상단에서 제거. 최초 접속 로고에 표시 |

월드맵 위에 별도 높이를 차지하던 정보바는 없다. 접속자 수만 상단 오버레이로 이동했다.

| 번호 | 이름 | 현재 상태·위치 |
| --- | --- | --- |
| B-1 | 소개 문구 | **제거** — `하나의 공간, 여러 개의 커서` 표시 없음 |
| B-2 | 화면 제목 | **제거** — `여기, 함께.` 제목 표시 없음 |

## C. 월드 화면 → 전체 화면 월드맵

**월드맵**, **월드 화면**, **뷰포트**는 지도 화면을 가리킨다. 월드맵은 화면 전체를 차지하고 이동이 끝나면 내 커서를 중심보다 조금 위에 맞춘다. 사용자의 후속 요청에 따라 이동 중의 엄격한 중심 고정보다 부드러운 움직임을 우선한다.

| 번호 | 이름 | 현재 상태·역할 |
| --- | --- | --- |
| C-1 | 글자 셀 / 기본 칸 | 기본 배율에서 가로 9px·세로 26px인 한 칸. 새 한글·한자·전각 문자는 가로 두 칸을 차지 |
| C-2 | 망점 | 격자선 대신 가로·세로가 같은 간격의 옅은 점. 지도 이동과 확대에 따라 함께 움직임 |
| C-3 | 공유 글자 | 사람들이 세계에 쓴 글자와 내 미확정 입력의 즉시 표시. 최종 내용은 서버 순서를 따르며 1칸 또는 2칸 사용 |
| C-4 | 내 커서 / 중심 커서 | 실제 입력할 세계 셀에 붙은 `#cursor` 표시. 화면 전환 중 잠깐 중심을 벗어났다가 이동 후 중심보다 조금 위으로 돌아옴 |
| C-5 | 상대 커서 | 다른 사용자의 세계 위치를 나타내는 색깔 칸 |
| C-6 | 사용자 이름표 | 상대 커서 위의 `여행자 1` 같은 라벨 |
| C-7 | 토러스 경계선 | **제거** — 세계의 양 끝은 계속 이어짐 |
| C-8 | 마우스 포인터 | 지도를 가리키거나 끌 때의 OS 포인터. 중심 커서와 별개 |
| C-9 | 방향 표시 | **제거** — `N ↑` 표시 없음 |
| C-10 | 미니맵 | **제거** |

| C-12 | 미니맵 내 위치 점 | **제거** |
| C-13 | 미니맵 상대 위치 점 | **제거** |
| C-14 | 미니맵 설명 | **제거** — `끝은 다시 시작으로` 표시 없음 |

### 지도와 커서의 관계

- 가로·세로 스크롤과 드래그로 지도를 움직이면 **내 커서의 세계 좌표가 바뀐다**. 이 좌표가 내 존재 위치이자 입력 위치이며 다른 사용자에게도 전달된다.
- 빠른 드래그를 놓으면 관성으로 이동하다 감속한다. 타이핑·조합 시작·새 터치·줌·GPS 등 명시적인 조작은 관성을 멈춘다. OS의 동작 줄이기 설정에서는 관성 이동을 끈다.
- 내 커서는 실제 입력할 셀을 가리킨다. 입력·방향키·스크롤에 따라 지도가 부드럽게 따라오며, 움직임이 끝나면 커서가 중심보다 조금 위에 놓인다.
- Enter·Shift+Enter는 이번 글쓰기를 시작한 열의 다음 행으로 간다. 모바일 줄바꿈·붙여넣기의 줄바꿈도 같은 규칙이다.
- 지도 드래그·스크롤·GPS·좌표 링크는 새로운 작성 기준을 잡는다. 글을 쓰는 중 방향키로 고치는 동작과 줌은 기존 기준을 유지한다. Home은 현재 행의 기준 열로 돌아간다.
- Backspace는 실제 작성 경로를 거슬러 글자를 지우며, 직접 만든 줄바꿈에서는 이전 줄 끝으로 이동만 한다. Delete는 현재 셀이 속한 글자를 비운다. 두 칸 문자는 어느 쪽 칸을 삭제·덮어써도 기존 글자 두 칸을 함께 정리해 반쪽이 남지 않는다. 자세한 비교는 [입력 설계](INPUT_DESIGN.md)를 참고한다.
- 지도 클릭/탭은 **현재 커서 셀에서 입력 시작**이다. 클릭한 화면 위치로 커서를 옮기지 않는다. 위치를 고르는 동작은 지도 이동이다.
- 세계의 입력 주소는 정수 칸으로 이동하지만 화면은 칸 사이도 부드럽게 움직인다. 직접 드래그는 손가락을 즉시 따르고, 진행 중인 전환을 잡으면 보이는 위치에서 이어 끈다. 놓은 뒤 관성과 재정착을 거쳐 중심보다 조금 위로 돌아온다.
- 지도 글꼴은 Sarasa Fixed K이며 기본 글꼴 크기 18px에서 반각 9px·전각 18px로 그린다. 한글·영문 모두 이전보다 가로 간격이 25% 좁다. 기존 저장 글은 좌표 보존을 위해 이전 1칸 폭을 유지하고 필요하면 작은 크기로 그리며, 다시 입력하면 새 폭을 적용한다.
- 화면 크기·모바일 키보드 높이가 바뀌면 지도 영역을 즉시 맞추고 커서를 새 정착점으로 부드럽게 옮긴다. 큰 화면 축소에서는 입력 셀이 가려지지 않도록 최소한의 위치 보정이 먼저 일어날 수 있다.

## 모바일과 네이티브 UI

데스크톱과 모바일 모두 전체 화면 지도와 이동 후 중심보다 조금 위으로 돌아오는 커서를 사용한다. 작은 화면에서는 오버레이 간격과 표시량을 줄인다. 키보드 높이가 바뀌면 새 지도 영역에 맞춰 전환하며 별도 입력 패널을 만들지 않는다. 동작 줄이기 설정에서는 전환을 즉시 마친다.

GPS 권한 팝업, 휴대폰 키보드, 한글 입력 후보창은 브라우저·운영체제가 제공하는 UI다. 지도를 탭해 입력을 시작하며, 키보드를 닫는 방식은 해당 운영체제의 동작을 따른다.

### 신선도와 색상

글자 자체의 투명도가 시간이 흐를수록 높아지며, 하한에 도달하면 자동 삭제된다. 배경 강조·삭제 흔적·범례는 표시하지 않는다. 작성자별 색은 익명 접속 세션에 배정된다. 색 변경은 백로그다.

### 최초 접속 로고

화면 한가운데 로고를 3초간 보여주고 페이드아웃한다. 같은 탭 세션의 새로고침에서는 다시 표시하지 않는다.
