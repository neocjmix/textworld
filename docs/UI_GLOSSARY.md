# Textworld UI 명칭 사전

현재 UI를 수정할 때 사용하는 공통 이름과 번호다. 예를 들어 “B 전체 없애”, “C-4 커서를 바꿔”, “E 입력 패널을 없애”처럼 지칭할 수 있다.

- 작성일: 2026-11-02
- 기준 구현: [`a9ddede`](https://github.com/neocjmix/textworld/tree/a9ddeded84aed638082756a47a1b0b1ba5e61441)
- 공개 서비스: https://textworld-production-987c.up.railway.app
- 구현 파일: [HTML](../public/index.html), [스타일](../public/style.css), [동작·Canvas 렌더링](../public/app.js)

이 문서는 현재 구현을 설명한다. 제품 헌법에 새로운 요구사항을 추가하지 않는다. 수정 요청의 혼선을 막기 위해 기존 번호는 다른 요소에 재사용하지 않고, 요소가 제거되면 제거되었다고 기록한다.

## 전체 구조

**B+C+D를 합쳐 ‘월드 패널’**이라고 부른다.

```text
┌──────────────────────────────────────┐
│ A. 상단바                            │
├──────────────────────────────────────┤
│ B. 월드 정보바                       │
├──────────────────────────────────────┤
│                                      │
│ C. 월드 화면 — 글자 격자와 커서       │
│                         [미니맵]     │
├──────────────────────────────────────┤
│ D. 월드 도구바                       │
└──────────────────────────────────────┘
┌──────────────────────────────────────┐
│ E. 입력 패널                         │
└──────────────────────────────────────┘
  F. 하단 안내바

  G. 도움말 패널 — ‘사용법’을 누르면 표시
```

## A. 상단바

화면 맨 위의 영역이다.

| 번호 | 이름 | 현재 모습·문구 |
| --- | --- | --- |
| A-1 | 로고 심벌 | 짙은 녹색 사각형 안의 `t_` |
| A-2 | 로고 글자 | `textworld` |
| A-3 | 에디션 문구 | `FIELD NOTES / 001` |
| A-4 | 연결 상태 점 | 연결 상태에 따라 색이 바뀌는 작은 원 |
| A-5 | 연결 상태 문구 | `연결 중` / `실시간 연결` / `재연결 중` |
| A-6 | 사용법 버튼 | `사용법 ?` |

A-1~A-3은 하나의 클릭 영역이며, 누르면 처음 주소(`/`)로 이동한다.

## B. 월드 정보바

격자 바로 위의 영역이다.

| 번호 | 이름 | 현재 모습·문구 |
| --- | --- | --- |
| B-1 | 소개 문구 | `하나의 공간, 여러 개의 커서` |
| B-2 | 화면 제목 | `여기, 함께.` |
| B-3 | 접속자 수 | `2명 접속` |
| B-4 | 세계 크기 표시 | `64 × 32` 등 가로·세로 칸 수 |
| B-5 | 세계 버전 표시 | `TORUS 2` 등 크기 변경 버전 |

B-4와 B-5는 현재 같은 줄에 표시된다. `TORUS` 뒤 숫자는 접속자 수나 앱 버전이 아니라 세계 크기 변경에 따른 epoch다.

## C. 월드 화면

글자가 놓이는 영역이다. **뷰포트**라고 해도 같은 화면 영역을 뜻한다.

| 번호 | 이름 | 현재 모습·역할 |
| --- | --- | --- |
| C-1 | 글자 셀 | 글자 하나가 놓이는 격자 한 칸 |
| C-2 | 격자선 | 칸 사이의 옅은 실선 |
| C-3 | 공유 글자 | 사람들이 세계에 쓴 실제 글자 |
| C-4 | 내 커서 | 녹색 테두리·반투명 배경·아래 짧은 선으로 표시한 한 칸 |
| C-5 | 상대 커서 | 다른 사용자의 위치를 나타내는 색깔 칸 |
| C-6 | 사용자 이름표 | 상대 커서 위의 `여행자 1` 같은 라벨 |
| C-7 | 토러스 경계선 | 세계의 좌표가 0으로 이어지는 곳의 점선 |
| C-8 | 마우스 포인터 | 격자 위에서 보이는 십자 모양 포인터 |
| C-9 | 방향 표시 | 오른쪽 위의 `N ↑` |
| C-10 | 미니맵 | 오른쪽 아래의 작은 세계 지도 전체 |
| C-11 | 미니맵 글자 점 | 글자가 있는 위치의 작은 점 |
| C-12 | 미니맵 내 위치 점 | 내 위치를 나타내는 녹색 점 |
| C-13 | 미니맵 상대 위치 점 | 다른 사용자 위치의 색깔 점 |
| C-14 | 미니맵 설명 | `끝은 다시 시작으로` |
| C-15 | 빈 세계 안내 | 처음 빈 세계에서 나타나는 중앙 안내 전체 |

C-15 **빈 세계 안내**는 다음 요소로 구성된다.

| 이름 | 현재 모습·문구 |
| --- | --- |
| 안내 아이콘 | `✳` |
| 안내 첫 문장 | `아직 비어 있는 곳.` |
| 입력 유도 문구 | `첫 글자를 남겨 보세요.` |
| 입력 방법 설명 | `칸을 누르고 입력하면 모두에게 보입니다.` |

- **내 커서(C-4)**와 **마우스 포인터(C-8)**는 서로 다른 요소다.
- 미니맵은 현재 표시용이며 클릭으로 이동하지 않는다. 현재 화면 범위를 나타내는 사각형 표시도 없다.
- 빈 세계 안내는 세계에 글이 있거나, 접속자가 둘 이상이거나, 이미 이동했다면 숨겨진다.
- 글자·격자선·커서·이름표·경계선·미니맵의 점은 Canvas에 그려진다.

## D. 월드 도구바

격자 바로 아래의 영역이다.

| 번호 | 이름 | 현재 모습·문구 |
| --- | --- | --- |
| D-1 | 내 위치 라벨 | 녹색 작은 사각형 + `나의 위치` |
| D-2 | 좌표 표시 | `5, 4` 같은 현재 커서 좌표 |
| D-3 | 축소 버튼 | `−` |
| D-4 | 확대 배율 표시 | `100%` |
| D-5 | 확대 버튼 | `+` |
| D-6 | GPS 이동 버튼 | `◎ 내 GPS 위치` |
| D-7 | 위치 링크 버튼 | `↗ 이곳 링크` |

D-3~D-5를 묶어서 **줌 컨트롤**이라고 부른다. 현재 확대 배율 범위는 60~200%이며, 한계에 도달하면 해당 버튼이 비활성화된다.

## E. 입력 패널

월드 패널 아래의 연녹색 영역이다.

| 번호 | 이름 | 현재 모습·문구 |
| --- | --- | --- |
| E-1 | 입력 라벨 | 녹색 작은 사각형 + `이곳에 쓰기` |
| E-2 | 쓰기 상태 문구 | `한 칸에 한 글자` / `글자를 보내는 중` / `모두에게 보입니다` / `입력을 확인해 주세요` |
| E-3 | 텍스트 입력창 | 키보드로 글자를 입력하는 실제 영역 |
| E-4 | 입력 예시 문구 | 입력창이 비었을 때 보이는 `안녕, 여기 있어요.` |
| E-5 | 덮어쓰기 안내 | `입력은 선택한 칸을 덮어씁니다.` |
| E-6 | 조작 안내 | `Enter 다음 줄 · 방향키 이동 · 드래그 탐색` |

입력창은 연결이 끊기면 비활성화된다. 입력 예시 문구는 placeholder이며 세계에 기록된 글자가 아니다.

## F. 하단 안내바

화면 맨 아래의 영역이다.

| 번호 | 이름 | 현재 모습·문구 |
| --- | --- | --- |
| F-1 | 하단 슬로건 | 왼쪽의 `A WORLD MADE OF WORDS` |
| F-2 | 상태 알림 | GPS·연결·링크 복사·입력 오류·세계 크기 변경 등의 안내가 바뀌어 나오는 자리 |
| F-3 | 공개 세계 표시 | 오른쪽의 `PUBLIC WORLD ↔` |

F-2는 같은 자리에 문구가 교체되는 상태 표시다. 여러 알림을 쌓아 보여주는 목록이나 별도 팝업은 아니다.

## G. 도움말 패널

사용법 버튼(A-6)을 누르면 열리는 패널이다. 같은 버튼을 다시 누르면 닫힌다.

| 번호 | 이름 | 현재 모습·내용 |
| --- | --- | --- |
| G-1 | 도움말 영문 문구 | `HOW TO INHABIT` |
| G-2 | 도움말 제목 | `글자가 풍경이 되는 곳` |
| G-3 | 이동·커서 설명 | 칸 선택, 다른 사용자, 화면 이동 설명 |
| G-4 | 입력·삭제 설명 | 덮어쓰기, Backspace, Delete, 붙여넣기 설명 |
| G-5 | 세계 구조 설명 | 토러스, 확장·축소, 글자 수명 설명 |
| G-6 | GPS·위치 공개 설명 | 위치 변환, 권한, 커서 위치 공개 설명 |
| G-7 | 재접속 설명 | `실험 001 · 연결이 끊기면…`으로 시작하는 마지막 문단 |

## 모바일 표시 차이

화면 폭 640px 이하에서는 같은 요소를 축소·재배치한다. 별도 모바일 UI 명칭을 사용하지 않는다.

| 요소 | 모바일 표시 |
| --- | --- |
| A-3 에디션 문구 | 숨김 |
| C-14 미니맵 설명 | 숨김 |
| D-6 GPS 이동 버튼 | `◎` 아이콘만 표시 |
| D-7 위치 링크 버튼 | `↗` 아이콘만 표시 |
| E-6 조작 안내 | 숨김 |
| F-1 하단 슬로건 | 숨김 |
| F-3 공개 세계 표시 | 숨김 |

GPS 권한 팝업, 휴대폰 키보드, 한글 입력 후보창은 브라우저·운영체제가 제공하는 UI다.
