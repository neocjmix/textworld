# Textworld UI 명칭 사전

현재 UI를 수정할 때 사용하는 공통 이름과 번호다. “C-4 중심 커서”, “D-6 GPS 이동 버튼”처럼 지칭할 수 있다. **C 월드 화면이 전체 화면이며, 내 커서는 항상 화면 중심에 있다. 지도 이동 자체가 커서 이동이고, 지도 위에서 네이티브 키보드로 바로 입력한다.**

- 갱신일: 2026-11-02 · 전체 화면 지도 UI
- 공개 서비스: https://textworld-production-987c.up.railway.app
- 구현 파일: [HTML](../public/index.html), [스타일](../public/style.css), [동작·Canvas 렌더링](../public/app.js)
- 이전 UI: [최초 명칭 사전](https://github.com/neocjmix/textworld/blob/1e998f6/docs/UI_GLOSSARY.md)

기존 번호를 다른 요소에 재사용하지 않는다. 제거된 요소도 번호와 이름을 남긴다. 이 문서는 현재 UI를 설명하며 `PRODUCT_CONSTITUTION.md`는 변경하지 않는다.

## 전체 구조

지도가 브라우저의 보이는 콘텐츠 영역 전체를 채운다. 예전처럼 A~F가 세로로 쌓여 지도 영역을 줄이지 않는다. 필요한 조작만 지도 위에 떠 있다.

```text
┌──────────────────────────────────────────┐
│ [브랜드·연결·접속자]        [공유][사용법] │
│                                          │
│                                          │
│          C. 전체 화면 월드맵              │
│                                          │
│                [내 커서]                 │
│                항상 중심                 │
│                                          │
│                                  [GPS]   │
│                                   [+]    │
│                                  [100%]  │
│ [좌표]                            [−]    │
└──────────────────────────────────────────┘

상태 알림은 필요할 때 잠깐 표시한다.
도움말 패널은 ‘사용법’을 누르면 지도 위에 열린다.
E 입력 패널은 없다. 지도 탭 → 현재 중심 셀에 입력한다.
```

모바일 키보드가 열리면 키보드를 제외한 **보이는 지도 영역의 중심**이 입력 위치다. 브라우저의 주소창이나 OS 화면까지 숨기는 Fullscreen API 모드를 뜻하지 않는다.

## A. 상단바 → 지도 위 상단 오버레이

기존 상단바의 배경 영역은 제거했다. 아래 요소는 지도 모서리에 작은 오버레이로 남긴다.

| 번호 | 이름 | 현재 상태·위치 |
| --- | --- | --- |
| A-1 | 로고 심벌 | 왼쪽 위 브랜드 표시 |
| A-2 | 로고 글자 | 왼쪽 위 `textworld` |
| A-3 | 에디션 문구 | **제거** — `FIELD NOTES / 001` 표시 없음 |
| A-4 | 연결 상태 점 | 왼쪽 위 연결 상태 표시 |
| A-5 | 연결 상태 문구 | `연결 중` / `실시간 연결` / `재연결 중` |
| A-6 | 사용법 버튼 | 오른쪽 위의 `?`, 도움말 열기 |

## B. 월드 정보바 → 제거

월드맵 위에 별도 높이를 차지하던 정보바는 없다. 접속자 수만 상단 오버레이로 이동했다.

| 번호 | 이름 | 현재 상태·위치 |
| --- | --- | --- |
| B-1 | 소개 문구 | **제거** — `하나의 공간, 여러 개의 커서` 표시 없음 |
| B-2 | 화면 제목 | **제거** — `여기, 함께.` 제목 표시 없음 |
| B-3 | 접속자 수 | 왼쪽 위 브랜드·연결 상태 옆에 표시 |
| B-4 | 세계 크기 표시 | **제거** — 가로·세로 칸 수를 상시 표시하지 않음 |
| B-5 | 세계 버전 표시 | **제거** — `TORUS n` 표시 없음 |

세계 크기와 epoch는 엔진에 그대로 존재한다. 화면에서 표시를 제거한 것이다.

| 번호 | 이름 | 현재 상태·역할 |

| C-2 | 격자선 | 칸 사이의 옅은 실선 |
| C-3 | 공유 글자 | 사람들이 세계에 쓴 실제 글자 |
| C-4 | 내 커서 / 중심 커서 | 항상 보이는 지도 화면의 중심에 놓인 입력 셀 |
| C-5 | 상대 커서 | 다른 사용자의 세계 위치를 나타내는 색깔 칸 |

| C-13 | 미니맵 상대 위치 점 | **제거** |

### 지도와 커서의 관계

- 가로·세로 스크롤과 드래그로 지도를 움직이면 **중심 셀의 세계 좌표가 바뀐다**. 이 좌표가 내 존재 위치이자 입력 위치이며 다른 사용자에게도 전달된다.
- 내 커서는 화면 중심을 벗어나지 않는다. 입력으로 다음 칸으로 진행하거나 방향키로 이동할 때 지도가 따라 움직인다.
- Enter·Shift+Enter는 이번 글쓰기를 시작한 열의 다음 행으로 간다. 모바일 줄바꿈·붙여넣기의 줄바꿈도 같은 규칙이다.
- 지도 드래그·스크롤·GPS·좌표 링크는 새로운 작성 기준을 잡는다. 글을 쓰는 중 방향키로 고치는 동작과 줌은 기존 기준을 유지한다. Home은 현재 행의 기준 열로 돌아간다.
- Backspace는 실제 작성 경로를 거슬러 글자를 지우며, 직접 만든 줄바꿈에서는 이전 줄 끝으로 이동만 한다. Delete는 현재 셀만 비운다. 자세한 비교는 [입력 설계](INPUT_DESIGN.md)를 참고한다.
- 지도 클릭/탭은 **현재 중심 셀에서 입력 시작**이다. 클릭한 화면 위치로 커서를 옮기지 않는다. 위치를 고르는 동작은 지도 이동이다.
- 카메라는 셀 단위로 움직인다. 작은 이동 입력은 누적해 다음 셀 이동에 반영한다.
- 줌·화면 크기 변경·모바일 키보드 표시에도 선택한 셀을 보이는 지도 영역의 중심에 유지한다.

## D. 월드 도구바 → 지도 위 조작 버튼

기존 가로 도구바는 제거하고 기능별로 지도 모서리에 배치했다.

| 번호 | 이름 | 현재 상태·위치 |
| --- | --- | --- |
| D-1 | 내 위치 라벨 | 왼쪽 아래 좌표 옆의 작은 위치 아이콘만 유지. `나의 위치` 글자는 제거 |
| D-2 | 좌표 표시 | 왼쪽 아래, 중심 커서의 현재 세계 좌표 |
| D-3 | 축소 버튼 | 오른쪽 아래 줌 컨트롤의 `−` |
| D-4 | 확대 배율 표시 | 오른쪽 아래 줌 컨트롤의 `100%` |
| D-5 | 확대 버튼 | 오른쪽 아래 줌 컨트롤의 `+` |
| D-6 | GPS 이동 버튼 | 오른쪽 아래, 현재 GPS에 해당하는 셀로 이동 |
| D-7 | 위치 링크 버튼 | 오른쪽 위로 이동, 현재 중심 셀의 링크 공유 |

D-3~D-5를 **줌 컨트롤**이라고 부른다. 확대 범위는 60~200%이며 한계에 도달하면 해당 버튼이 비활성화된다.

## E. 입력 패널 → 제거

지도 밖의 별도 입력 영역은 없다. 아래 번호는 이전 UI를 지칭하기 위해서만 보존한다.

| 번호 | 이름 | 현재 상태 |
| --- | --- | --- |
| E-1 | 입력 라벨 | **제거** — `이곳에 쓰기` 없음 |
| E-2 | 쓰기 상태 문구 | **제거** — 입력 패널의 상시 상태 표시 없음 |
| E-3 | 텍스트 입력창 | **별도 UI 제거** — 지도 중심에서 직접 네이티브 입력 |
| E-4 | 입력 예시 문구 | **제거** — `안녕, 여기 있어요.` placeholder 없음 |
| E-5 | 덮어쓰기 안내 | **입력 패널에서 제거** — 도움말에서 설명 |
| E-6 | 조작 안내 | **입력 패널에서 제거** — 도움말에서 설명 |

네이티브 키보드와 한글 조합을 받기 위한 실제 textarea는 내부적으로 중심 셀에 존재하지만, 별도 패널·테두리·placeholder를 보여주지 않는다. 화면에서 보이는 입력 위치는 C-4 중심 커서다. 조합 중 글자는 C-16에 표시한다.

| 번호 | 이름 | 현재 상태·위치 |
| --- | --- | --- |
| F-1 | 하단 슬로건 | **제거** — `A WORLD MADE OF WORDS` 없음 |

| F-3 | 공개 세계 표시 | **제거** — `PUBLIC WORLD ↔` 없음 |

## G. 도움말 패널

사용법 버튼(A-6)으로 지도 위에 여는 패널이다. 지도 중심 입력 방식에 맞춰 내용을 수정했다.

| 번호 | 이름 | 현재 상태·내용 |
| --- | --- | --- |
| G-1 | 도움말 영문 문구 | **제거** — `HOW TO INHABIT` 없음 |
| G-2 | 도움말 제목 | `지도를 움직이고, 그 자리에 쓰세요.` |
| G-3 | 이동·커서 설명 | `01 가운데가 내 자리` — 지도 이동과 중심 커서 설명 |
| G-4 | 입력·삭제 설명 | `02 지도에 바로 입력`과 키보드 안내 — 네이티브 입력·방향키·Enter·Home·Backspace·Delete 설명 |
| G-5 | 세계 구조 설명 | 상세 설명 안의 경계 연결·확장·축소·글자 수명 설명 |
| G-6 | GPS·위치 공개 설명 | 상세 설명 안의 GPS 변환과 다른 사용자에게 보이는 위치 설명 |
| G-7 | 재접속 설명 | 상세 설명 안의 연결 중단·자동 재접속 설명 |
| G-8 | 도움말 닫기 버튼 | 도움말 패널 오른쪽 위의 `×` |
| G-9 | 상세 설명 펼치기 | `세계와 위치에 관하여` — G-5~G-7을 펼치고 접는 컨트롤 |
| G-10 | 함께 쓰기 설명 | `03 같은 칸을 함께` — 상대 커서·덮어쓰기·입력 시 지도 이동 설명 |

## 모바일과 네이티브 UI

데스크톱과 모바일 모두 전체 화면 지도와 중심 커서를 사용한다. 작은 화면에서는 오버레이 간격과 표시량을 줄인다. 키보드가 뜨면 보이는 지도 영역에 맞춰 중심을 다시 계산하며 별도 입력 패널을 만들지 않는다.

GPS 권한 팝업, 휴대폰 키보드, 한글 입력 후보창은 브라우저·운영체제가 제공하는 UI다. 지도를 탭해 입력을 시작하며, 키보드를 닫는 방식은 해당 운영체제의 동작을 따른다.
