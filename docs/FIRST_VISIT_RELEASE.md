## 같은 조건에서의 전후 비교

변경 전 `04461cc`, 변경 후 `705d1f2`. Chromium 156, 모바일 390×844, CDP로 다운로드 **2Mbps**, 업로드 1Mbps, 지연 **150ms**를 설정했다. 각 조건은 독립 캐시의 첫 방문 3회와 그 직후 새로고침 3회다. 아래는 중앙값이다. 입력 준비는 연결·목표 좌표·카메라 안정화를 확인한 시점이며, 글꼴 표시 완료는 실제 시야를 그린 뒤 해당 글꼴 다운로드와 다음 프레임까지 기다린 시점이다. 네트워크 시뮬레이션의 지연값을 실제 이동통신 RTT라고 단정하지 않는다.

## 구현과 판단

- HTML·JS·CSS에 gzip과 ETag를 적용했다. 변경되지 않은 페이지는 304로 재사용한다. 배포로 바뀐 파일은 다시 받으며 원래 버전 WOFF2의 장기 캐시는 유지한다. 읽기·압축 결과의 보관은 프로세스당 8MiB로 제한한다.
- 원본 Sarasa의 51,228개 문자를 줄이지 않고 30개 파일로 나눴다. 기본 파일 476,924 B를 미리 받아 연결하고, 나머지는 CSS unicode-range로 필요할 때 받는다. FontFaceSet의 완료 이벤트에서 정지한 Canvas도 다시 그린다.
- 한글 자모·완성형은 분리하면 정규화 결과가 달라져 같은 파일에 묶었다. 원본의 모든 문자·advance·윤곽 좌표와 플래그·변형 선택자 매핑을 빌드에서 대조했다. 일부 안티앨리어싱 픽셀은 달라지므로 래스터 완전 일치는 보장하지 않는다. 실제 Sarasa 웹 글꼴 사용과 원본/분할본 화면을 확인했다.
- 시스템 글꼴만 쓰거나 인기 문자만 남기는 방식은 일관된 표시와 기존 지원 범위를 유지하기 어려워 제외했다. 새 폰트 CDN·전송 프로토콜·분산 서버는 추가하지 않았다.

원본 전체 5,315,944 B에 비해 모든 분할 파일 합계는 5,949,384 B다. 모든 문자 범위를 돌아다니는 방문에는 분할이 총 글꼴 바이트를 줄이지 않는다. 새 범위를 처음 읽을 때 대체 글꼴이 잠깐 보인 뒤 바뀔 수 있지만 셀의 폭·좌표·문맥은 바뀌지 않는다. [의사결정](DECISIONS.md) · [재생성과 라이선스](../public/fonts/README.md)

## 실제 검증

- Node 회귀 **276개** 통과. 별도로 바뀐 원가 모형·HTTP 조건부 응답 8개를 재확인했다.
- Chromium·Firefox·WebKit 각각 두 참여자의 CJK 입력·덮어쓰기·Enter·Backspace·방향키·터치 입력·모바일 화면·새로고침 수렴을 확인했다.
- 세 엔진에서 각각 20개 글꼴 로딩/폭/한글 정규화 검사와 다운로드를 고의로 지연시킨 뒤 유휴 지도 재표시를 통과했다. WebKit의 FontFaceSet.check 반환값만으로 준비 여부를 판정하지 않고 해당 FontFace 상태를 확인했다.
- Chromium IME 15개, CJK 10개, 300ms 응답 지연을 넣은 타이핑 9개, 기본 브라우저 25개, 뷰포트 전환 9개, 모션 10개를 확인했다. 물리 Android/iOS 키보드를 직접 조작한 검증은 아니다.
- 모션 검사는 병렬 실행 중 터치 관성 시작 단언에서 한 번 실패했고, 같은 코드의 독립 재실행은 통과했다. 초기 시야의 Canvas가 요청하는 글꼴과 카메라 안정화를 기다린 뒤 시간에 민감한 제스처를 시작하도록 시험 준비를 보완했다. 실패 로그도 원자료에 남겼다.
- 공개 Railway에서 실제 HTTPS, 두 WSS 접속, CJK와 Enter 입력의 상대방 관측, 강제 연결 종료 후 재접속 수렴, 오류 없는 데스크톱/모바일 화면을 확인했다. 440px로 축소한 가상 키보드 viewport에서 커서는 y=384px에 정착했다.

## 원가와 공개 판단

동접 300명이 이전 한 시간 실험의 활동 비율로 30일 연속 접속하고, 평균 체류 20분·방문 20%의 글꼴 추가 다운로드를 가정한다. 혼합 시야에서 실측한 글꼴 분량을 적용하면 **월 $92.11, 주 $21.49**다. 이전 $116.82 대비 약 $24.71 감소한다. 페이지 압축과 글꼴 전송만 갱신했고 실시간 송신·CPU/RSS는 이전 실측을 재사용했다. 새 캐시가 전부 추가되는 경우의 8MiB 메모리는 월 약 $0.084이며 별도로 지속 측정한 값은 아니다.

방문자가 모든 글꼴 조각을 받는 가정이면 **월 $118.52**다. 밀집 시간, 방문 빈도, 처음 읽는 문자 범위에 따라 바뀌며 총 청구액이나 $100 이내를 보장하지 않는다. 페이지의 304 절감은 원가에 넣지 않아 방문당 페이지 비용은 보수적으로 잡았다. [수식·가정과 공간 배치별 비용](OPERATING_COST_MODEL.md)

**초기 공개 가능**으로 판단한다. 안전 상한은 앞서 검증한 300명을 유지한다. 추가 전송·분산 최적화는 중단하고 실제 초대 방문자의 첫 글, 응답, 재방문을 관찰할 단계다. 잔여 사항은 물리 모바일 IME/키보드 체감, 실제 언어별 글꼴 다운로드 분포, 첫 방문 실패율, 실사용 밀집도다. 단일 서버의 배포/장애 중단과 아주 넓은 문자 탐색 비용은 여전히 존재한다. 다음 실험은 실제 방문 세션에서 첫 입력까지 걸린 시간과 관측된 글꼴 범위가 이 fixture와 얼마나 다른지 확인하는 것이다.
