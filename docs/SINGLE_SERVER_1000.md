## 원가와 보류한 개선

실시간 송신이 원가의 대부분이다. 한 시간의 활동 평균과 별도 공개 볼륨 측정을 사용하면 평균 1,000명 상주·20분 체류·20% 혼합 글꼴 다운로드 가정에서 월 **$218.04**다. 정적 CDN 바이트 적중률 95%를 가정하면 **$175.90**이며 이 적중률은 아직 실제 사용자 통계가 아니다. 일주일은 각각 $50.88 / $41.04다. TLS·재전송·다른 서비스·세금·플랜 최소액은 빠진 추정이다. [산출식·출처·민감도](OPERATING_COST_MODEL.md)

전송량을 더 줄이기 위한 상태 사전·바이너리, 구역별 관측 봉투 공유, 압축 기본 활성화, P2P·WebTransport·분산 서버는 이번에 도입하지 않는다. 작은 코드 변경과 실측으로 얻은 개선을 유지하고, 후속 작업은 실제 사용자 자료에서 필요가 확인될 때 한다.

- 극단적으로 밀집한 곳의 첫 자리 이동과 재접속 대기. 현재 보호는 거절로 서버를 지키지만 특정 요청의 빠른 승인을 보장하지 않는다.
- 큰 세계·최대 허용 시야·많은 활동자가 동시에 몰리는 경우. 시험한 52×40/150×50 혼합과 1,000명 전원 활동은 다른 부하다.
- 밀집한 커서의 이름표 겹침. 전체 커서 존재를 유지하면서 글을 가리지 않는 표시 방법은 별도 UI 실험으로 남긴다.
- 실물 저사양 휴대폰, OS 가상 키보드·IME, 여러 지역의 이동통신 회선과 손실. 브라우저 엔진/모바일 크기 검증으로 대신하지 않는다.
- 실제 방문자의 체류·활동률·시야 중첩·언어와 CDN 바이트 적중률. 이 분포가 생겨야 더 일반적인 원가 함수를 검증할 수 있다.
- 무중단 재시작·고가용성은 제공하지 않는다. 단일 서버 재배포 시 재연결하며 미확정 입력을 자동 재실행하지 않는다.

## 운영 판정

1,000명 정상 혼합 부하의 판정은 미확인·비계획 종료·관측 순번 공백·기준 불일치·내용 대조 차이 0, 예정 입력→ACK p95 150ms, 서버 전송 준비 p95 100ms, 다른 독자 디코딩 p95 200ms, 재입장 p95 1초, 만료 나이 p95 200초를 사용한다. 독자 200ms는 [이번 최적화 실험안](OPTIMIZATION_OPTIONS.md)의 기준이며 이전 300명 공개판의 150ms 목표와 구분한다. 구간별 꼬리 지연·재입장 p99·저장량과 최악의 밀집 거절률도 별도로 공개한다. 좌석 수를 늘려도 승인하지 못한 행동을 성공 건수로 계산하지 않는다.

- 한 시간과 입력 중단 뒤 풍화·삭제·축소·이력 회수는 완료했다. 마지막 입력 범위 방어는 별도 표본이다.
- 1,000명 밀집 급증은 초기 자리 이동 지연과 발생기의 연결 취소가 있었고, 공개 시험은 사람의 낮은 빈도 입력에도 429를 반환했다. 전체 서버 붕괴는 막았지만 정상 품질 통과가 아니다.
- **공개 운영 상한은 300명이다.** 1,000명은 위 혼합 활동 조건의 용량 증거로만 남긴다. 더 높은 상한의 공정한 입력 승인 정책은 별도 후속 작업이며 이번에 예약 큐·분산 계층을 추가하지 않는다.
